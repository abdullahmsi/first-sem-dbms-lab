# First Semester DBMS Lab (`first-sem-dbms-lab`)

This repository contains my practical lab assignments for the Year 1, Semester I Database Management System (DBMS) Lab. It covers implementing database concepts using SQL, designing schemas, and performing data manipulation and retrieval.

## What's Inside

* **Basic SQL & Table Operations (Q1 – Q13):** Creating databases and tables, applying constraints (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`), inserting, updating, deleting, filtering (`WHERE`, `DISTINCT`, `ORDER BY`), and altering table structures[cite: 3].
* **Aggregations, Joins & Subqueries (Q14 – Q20):** Using `SUM`, `AVG`, `COUNT`, grouping data with `GROUP BY` and `HAVING`, performing `INNER`, `LEFT`, `RIGHT`, and `FULL OUTER` joins, and writing nested queries with `IN`, `EXISTS`, and `NOT EXISTS`[cite: 3].
* **Views, Indexes & Built-in Functions (Q21 – Q25):** Creating views, indexing for query performance, and working with string (`UPPER`, `LOWER`, `LENGTH`), numeric (`ROUND`, `MOD`), and date/time functions[cite: 4].
* **PL/SQL & Transactions (Q26 – Q32):** Writing stored procedures, functions, cursors, triggers, exception handling blocks, managing transactions with `COMMIT` and `ROLLBACK`, and demonstrating ACID properties[cite: 4].
* **Database Design & Normalization (Q33 – Q35):** Normalizing tables into 1NF, 2NF, and 3NF, designing ER diagrams for real-world systems, and converting them into relational schemas using SQL[cite: 4].
