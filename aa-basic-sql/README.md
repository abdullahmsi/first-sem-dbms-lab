## Key Concepts Practiced
* **DDL (Data Definition Language):** `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`
* **DML (Data Manipulation Language):** `INSERT INTO`, `UPDATE`, `DELETE`
* **DQL (Data Query Language):** `SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`
* **Integrity Constraints:** `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`
